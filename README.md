# Tape-Machine-Tracker 🎛️

Eine Python-Web-App (basierend auf **Streamlit**) für macOS, die verschiedene Online-Marktplätze gezielt nach neu eingestellten analogen Bandmaschinen durchsucht.

### Hintergrund & Nutzen
Als technisch versierter Musiker und Liebhaber klassischer Studio-Hardware wollte ich verhindern, seltene Angebote auf Gebrauchtplattformen zu verpassen. Statt täglich manuell mehrere Webseiten zu prüfen, startet diese App per Doppelklick über eine macOS `.command`-Datei (`Tape_Radar.command`) und zeigt mir neue Inserate übersichtlich im Browser an.

### Funktionen
* **Interaktive Oberfläche:** Übersichtliche Darstellung der Suchergebnisse im Browser dank Streamlit.
* **Multi-Plattform-Suche:** Überwacht parallel 3 verschiedene Verkaufsplattformen nach definierten Suchbegriffen.
* **1-Klick-Start unter macOS:** Automatisierter Start über ein Bash/Shell-Skript (`.command`).

### Verwendete Technologien
* **Python 3**
* **Streamlit** (Web-Interface)
* **macOS Shell / Bash** (`.command` Starter)
* **Visual Studio Code**
